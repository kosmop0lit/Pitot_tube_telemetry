PITOT MONITOR — WINDOWS
=======================

Версія: v8 — виправлена прив'язка даних до часу та збільшені графіки.

Запуск:
1. Розпакуйте архів.
2. Запустіть run.bat.
3. Оберіть COM-порт Arduino Nano.
4. Натисніть «Підключити».

Що виправлено у v8:
- Час точки більше не береться з моменту, коли GUI обробив чергу Serial.
- Дані Serial отримують стабільну часову послідовність із кроком 0,10 с, що відповідає поточному Arduino-коду з MEASURE_INTERVAL=100 мс.
- Якщо між пакетами є реальна пауза понад 0,25 с, вона зберігається на часовій осі.
- Через це зникають хибні вертикальні «голки» та стиснуті пачки точок, які виникали, коли Windows обробляв кілька рядків одночасно.
- 6 графіків тепер розташовані 2 колонки × 3 ряди, тому кожне вікно значно більше.
- AUTO масштабує Y тільки тоді, коли дані реально виходять за межі поточного діапазону, а не перебудовує вісь на кожній точці.

Керування графіками:
- Колесо миші над графіком — плавний масштаб X+Y.
- Ctrl + колесо — масштаб тільки по Y.
- Shift + колесо — масштаб тільки по X.
- Затиснути ЛКМ і перетягнути — панорамування.
- Вісь часу завжди починається з 0 с і рухається тільки вперед.
- AUTO ON — автоматичне стеження за Y та поточним часом.
- Якщо нове значення виходить за межі Y, AUTO збільшує масштаб.
- RESET — повний огляд від 0 с до поточного часу та автоматичний Y.

Графіки:
- Температура T1
- Температура T2
- Статичний тиск Ps
- Повний тиск Pt
- Швидкість
- Густина повітря

Підтримувані формати Arduino:
- Старий: T1=... T2=... Ps=... Pt=... dP=... V=... rho=... ERR=...
- Новий діагностичний CSV: P_TOTAL_Pa,P_STATIC_Pa,DELTA_RAW_Pa,DELTA_Pa,SPEED_ms,SPEED_kmh,TEMP_C

Важливо:
Поточний Arduino-код має інтервал вимірювання 100 мс. Якщо цей інтервал буде змінено, значення nominal_sample_period у pitot_monitor.py потрібно змінити відповідно.


Версія v8: шість графіків розміщені 3×2, журнал помилок має постійну видиму область унизу та окремі вертикальний і горизонтальний скролбари.
